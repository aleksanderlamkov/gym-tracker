# Gym Tracker — правила проекта

## Язык
- Всегда только **русский** — и в размышлениях, и в ответах пользователю. Никакого английского в тексте, комментариях к пользователю и коммитах.

## Версия и релиз
- При **каждой** осмысленной правке поднимай версию в `package.json` по semver:
  - **patch** (1.1.0 → 1.1.1) — багфиксы и мелочи;
  - **minor** (1.1.0 → 1.2.0) — новые фичи;
  - **major** — несовместимые изменения.
- Версия — единый источник в `package.json`. В UI пробрасывается через `__APP_VERSION__` (vite `define`) и показывается на экране «Ещё». **Не хардкодить** версию в компонентах.
- Смысл правила: пользователь по номеру версии в «Ещё» видит, что обновление реально доехало на устройство.

## Коммиты, пуш, деплой
- Коммить и пушь **сам**, без отдельной просьбы, как только правка завершена и проверена. Сообщения коммитов — на русском.
- Репозиторий trunk-based: коммить прямо в `main`, без веток и PR. Push в `main` = авто-деплой (GitHub Actions → ветка `gh-pages` → GitHub Pages).
- `gh` CLI на машине нет — только `git` и `curl` (статус прогонов/Pages смотри через GitHub REST API).
- Прод: https://aleksanderlamkov.github.io/gym-tracker/ . После пуша Pages-CDN обновляется с задержкой (гитхабовский «pages build and deployment» + кэш CDN) — это нормально, дождись, а не пере-деплой.

## Перед коммитом
- Прогони `npm run build` (это `tsc && vite build`) — должно быть зелёным.
- Не коммить тестовые/сид-данные, отладку и временные файлы.
