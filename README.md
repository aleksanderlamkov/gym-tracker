# Gym Tracker

Персональный PWA-трекер силовых тренировок. Клон iOS-приложения Gym Tracker, заточенный под себя: программы → тренировки по дням → подходы (вес × повторы), графики прогресса, импорт бэкапа из оригинального приложения.

## Стек

Vite + React + TypeScript. Без бэкенда: все данные в `localStorage`. PWA (vite-plugin-pwa): офлайн-режим, установка на домашний экран iPhone.

## Команды

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # прод-сборка в dist/ (+ service worker)
npm run preview  # локальный просмотр прод-сборки
```

## Деплой

Собранный `dist/` — статика, хостится где угодно (GitHub Pages, Netlify, Vercel). Нужен **HTTPS**, иначе сервис-воркер (офлайн) не заработает. `base: './'` уже настроен — работает и из подпапки.

На iPhone: открыть сайт в Safari → «Поделиться» → «На экран “Домой”».

## Импорт старых данных

Ещё → Импорт бэкапа → выбрать файл `.gymtracker` (экспорт из оригинального приложения) или `.json` (собственный экспорт этого приложения). Импорт заменяет текущие данные.

Особенности маппинга `.gymtracker` — в `src/lib/importGymTracker.ts`:
- дата тренировки берётся из `calendarDays.trainingId` (сами `trainings` без дат);
- `isWeightDoubled` → флаг «×2» (вес на каждую руку), тоннаж считается вдвое;
- кардио/планки хранят `timeInMinutes`/`distance` — метрика упражнения определяется по фактическим данным.

## Структура данных

Одна запись в `localStorage` (`gym-tracker:data:v1`): `exercises` (справочник), `programs` (шаблоны на день), `workouts` (тренировки с датой и подходами). Экспорт/импорт — в настройках.
